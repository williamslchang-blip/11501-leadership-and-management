## 📌 課程簡介與架構理念 (Curriculum Architecture)

本課程專為 EMBA 高階經理人量身打造，破除「領導只憑天生魅力與直覺」的迷思，強調領導是一套**心智、人際、團隊與組織彼此連動的管理系統**。

### 🌟 11 階段演進心法路徑 (Evolutionary Roadmap)
```
認識領導 ➔ 認識自己 ➔ 如何帶不同的人 ➔ 如何激勵 ➔ 如何溝通 ➔ 如何帶團隊 ➔ 如何處理衝突 ➔ 如何運用影響力 ➔ 如何決策 ➔ 如何管理自己情緒 ➔ 如何帶領組織改變
```

### 🏆 四大領導躍遷階段 (4-Phase Leadership System)
1. **Phase 1: Lead Yourself 領導自我**（認識領導 ➔ 風格自我覺察 ➔ 決策除錯 ➔ 情緒智商修練）
2. **Phase 2: Lead People 領導個體**（情境領導因材施教 ➔ 激勵動機 ➔ 深度溝通與同頻傾聽）
3. **Phase 3: Lead Teams 領導團隊**（團隊建立與心理安全感 ➔ 衝突談判 ➔ 權力、影響力與組織政治）
4. **Phase 4: Lead Change 變革領導**（組織文化深層潛規則 ➔ 抗拒是情報 ➔ Kotter 4階段變革落地）

## 💻 網站技術特色與操作指引

* **All-in-One Standalone 模式**：所有網頁皆為單一自包含 HTML 檔案（內嵌 Tailwind CSS、FontAwesome、Chart.js 圖表、投影片簡報資料與本地存檔功能），支援離線瀏覽。
* **雙模式自由切換**：
  * 🎓 **學員互動模式**：沈浸於案例思辨、線上評估與反思卡填寫。
  * 👨‍🏫 **教師授課導引模式**：解鎖各單元的教學心法、提問引導策略、板書整理提示與盲點解析。
* **180 分鐘課堂計時儀表板**：內建 3 分鐘思考、10 分鐘休息、15 分鐘診斷、20 分鐘演練、40 分鐘講授快速載入按鈕。
* **全螢幕 24–30 頁 PPT 簡報放映**：支援鍵盤快捷鍵（`←` / `→` / `Space` / `ESC`）與講者備忘提示。
* **One-Minute Paper 智慧反思卡**：支援 LocalStorage 自動存檔、一鍵複製與列印/匯出 PDF。
