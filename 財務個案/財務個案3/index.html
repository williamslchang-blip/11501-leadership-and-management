Stephenson Real Estate Company：
資本結構重組、利息稅盾價值與融資決策抉擇

面對一筆高達 1.1 億美元（USD 110,000,000）的高科技走廊核心商業地塊法拍收購良機，堅持 25 年「零負債」的創辦人兼執行長，與堅持 MM 定理利息稅盾的財務長在董事會爆發正面攤牌！

目前流通股數：1,500 萬股
目前公開市價：$34.50 美元
無負債總市值：$5.175 億美元
綜合所得稅率：40.0%

決策衝突場景：十月下旬的董事會融資攤牌

執行長主張：零負債防線 方案 A (全額發股)

「四十年前，我創辦的建築承包公司在沃爾克 20% 高利率下被債務利息生生勒死。那場個人破產讓我失去了聲譽與十年心血。二十五年來，SRE 堅持零負債運作！增發股票雖然增加股數，但永遠不需還本付息，絕無破產風險！」

— 羅伯特·史蒂芬森，創辦人兼執行長
財務長建言：利息稅盾紅利 方案 B (全額發債)

「在 40% 企業所得稅體系下，堅守『零負債』是白白浪費 4,400 萬美元的利息稅盾價值（Tc × D）！發行債券能讓既有股東每股實質增值 $2.93 美元，股價自 $34.50 飆升至 $37.43。董事會負有對全體股東的信託責任，不發債即代理失靈！」

— 馬克·普萊斯，財務長 (CFO)

個案五大核心研討問題（Discussion Questions）

問題一（融資建議）：如果董事會的目標是最大化股東財富與公司價值，應選擇發債還是發股？闡述 MM 定理利息稅盾的創造原理。
問題二（市場價值資產負債表）：編制宣告前市場價值資產負債表，說明為何評估資本結構重組必須使用市場價值而非會計帳面價值。
問題三（方案 A 增發新股精算）：計算專案 NPV、宣告後股價、需增發的新股股數（318.84萬股），編制增發後市場價值資產負債表並分析股權稀釋效應。
問題四（方案 B 發行債券精算）：計算 4,400 萬美元利息稅盾現值、宣告後每股股價（$37.43）與淨增幅（+$2.93），證明股東財富增加額與稅盾的等價性。
問題五（MM第二定理與代理衝突）：深入證明為何負債提高股權成本（Re 上升）但 WACC 反而下降？剖析執行長創傷偏誤與董事會信託責任。

專為商管學院 MBA、EMBA 及高階公司金融課程設計。本指引提供 90 分鐘與 180 分鐘課堂時間表、黑板板書四象限（Board Plan）、蘇格拉底式提問引導與破題策略。

五大核心教學目標（Pedagogical Objectives）

1. 掌握 MM 定理有稅模型與利息稅盾 透徹理解所得稅體系下利息稅前扣除帶來的政府補貼（$PV(TS) = T_c \times D$），破除負債必然有害的直覺迷思。
2. 熟練編制市場價值資產負債表 跳脫會計歷史成本框架，從未來現金流折現與公允市價維度動態追蹤增資與發債對公司價值的衝擊。
3. 精準量化融資對每股股價的定價衝擊 證明在有效市場假說下，負債稅盾財富由既有舊股東獨享，推動每股股價自 $34.50 跳升至 $37.43。
4. 解析 MM 第二定理與 WACC 下降機制 理解財務槓桿提高推升股權風險（Re 上升）的同時，低成本負債的權重效應反而拉低 WACC 的精妙動態。
5. 剖析經理人個人創傷偏誤（Trauma Bias）與代理衝突 診斷創辦人早年破產創傷如何轉化為過度風險厭惡，損害股東利益，並探討董事會如何落實法定信託義務。

黑板板書四象限規劃圖（Board Plan）

【板書第一區：SRE 現況與購地機會】

• 股數 N0 = 15.0M 股 ； 股價 P0 = $34.50 ； 市值 VU = $517.5M
• 稅率 Tc = 40.0% ； 購地支出 I = $110.0M ； 專案無槓桿 NPV = $0
• 核心死結：執行長 1980 年代承包商破產創傷 → 堅持零負債

【板書第二區：方案 A 全額增發新股】

• 專案 NPV = $0（無稅盾，無超額價值）
• 新股價維持 P1 = $34.50 ； 增發新股 = $110M / $34.50 = 3.19M 股
• 總股數膨脹至 18.19M 股 ； 舊股東財富零增長 ($517.5M)

【板書第三區：方案 B 全額發行長期債券】

• 利息稅盾現值 PV(TS) = Tc × D = 40% × $110M = $44,000,000 美元！
• 總市值 VL = $671.5M ； 股權市值 S = $561.5M ； 股數維持 15M 股
• 新股價 P1 = $37.43 ； 每股淨漲 +$2.93 (+8.50%) ； 舊股東獨享44M

【板書第四區：資本成本演化與公司治理】

• MM 第二定理：Re 從 10.0% 微升至 10.24%
• 稅後債務成本僅 4.80% → 綜合 WACC 從 10.0% 驟降至 9.34%
• 治理建言：董事會堅守 Fiduciary Duty，通過發債並給予股權激勵

MM 第二定理之理論證明（為何 Re 上升，股價反而上漲？）

$$R_e = R_U + (R_U - R_d)(1 - T_c)\left(\frac{D}{S}\right) = 10.0\% + (10.0\% - 8.0\%)(1 - 0.40)(0.1959) = 10.24\%$$ 雖然股東要求的必要報酬率因承擔財務風險由 10.0% 微升至 10.24%，但因為新增負債的稅後邊際成本僅為 $R_d(1 - T_c) = 8.0\% \times 0.6 = 4.80\%$。 低成本負債的權重效應壓倒性拉低了加權平均資金成本： $$\text{WACC} = \left(\frac{561.5}{671.5}\right) \times 10.24\% + \left(\frac{110.0}{671.5}\right) \times 4.80\% = 9.34\%!$$ 折現率下降，公司市場總價值自然暴增，推動每股股價由 $34.50 飆升至 $37.43！
